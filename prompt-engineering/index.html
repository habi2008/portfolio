Constraint Control — IP vs MAC

Task 
Explain IP address vs MAC address under strict limits on length,
structure, vocabulary, and examples.
My Prompt 
You are a person who knows computers inside out. You have completed all the below phd's
PhD in Computer Networks
PhD in Telecommunications
PhD in Cybersecurity
PhD in Distributed Systems
PhD in Embedded Systems
PhD in Wireless Communications
PhD in Systems Engineering

Explain IP address vs MAC address in under 80 words that mandatorily must include one clear
example demonstrating the contrast.

DO NOT use any technical jargon except for the two terms IP address vs MAC address.
Make sure the explanation is under 80 words and in 2 paragraphs (HIGHLY MANDATORY)
and use simple language.

First paragraph MUST include the definition of what IP address and MAC address are
(without any technical jargon).

Second paragraph MUST include the example.

NON NEGOTIABLE CONSTRAINTS:
2 paragraphs
Under 80 words
Example in the second paragraph
NO technical jargon

Do all of the above with the provided constraints, nothing more nothing less,
and at any cost do not break any of the constraints.

Role + Structure Control — SQL Injection

Task 
Explain SQL Injection to beginners while enforcing role, audience,
structure, and language constraints.
My Prompt 
You are a university lecturer with a PhD in Cybersecurity and Computer Science
and you specialize in SQL injection.

You are going to give a lecture to First year IT students so keep in mind that
NO TECHNICAL JARGON is allowed to be used.

Explain SQL Injection by starting from high school level concepts and
gradually escalating, making the learning seamless.

Explain ONLY the following:
Definition → What SQL Injection is
Why it happens → Why systems are vulnerable
Real-life example → Non-technical, safe example

Language must be extremely simple. Use analogies and familiar concepts.
Teach like Richard Feynman.

Do not add anything else.
Follow exactly this structure.
